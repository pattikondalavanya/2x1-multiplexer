2x1 Multiplexer in Verilog This project implements a 2x1 Multiplexer using Verilog HDL. A multiplexer selects one of the two input lines based on the select signal and forwards it to the output. ## Truth Table | S | Y | |---|---| | 0 | I0 | | 1 | I1 | ## Files - `mux_2x1.v` – Verilog source code - `mux_2x1_tb.v` – Testbench - `simulation_output.txt` – Simulation results - `README.md` – Project documentation ## How to Run Using ModelSim or any Verilog simulator: 1. Compile the files 2. Run the testbench 3. View the waveform or console output
